# Sales & Business Insights Dashboard

This is a Power BI dashboard project created to analyze sales, profit, customers, and employees using business data.

## About the Project

The main goal of this project is to understand business performance through interactive dashboards and visualizations.

The project contains the following pages:

- Sales & Profit Insights
- Customer Insights
- Employee Insights
- Sales Breakdown & Analysis

## What I Analyzed

### Sales & Profit
- Total Sales
- Total Profit
- Total Orders
- Average Order Value
- Profit Margin
- Sales by Channel
- Sales by Country
- Profit by Product
- Profit Growth

### Customer Analysis
- Total Customers
- Customer Lifetime Value
- Customer Satisfaction
- Customers by Gender
- Customers by Age Group
- Customers by Loyalty Tier
- Customers by Country

### Employee Analysis
- Total Employees
- Active and Inactive Employees
- Employees by Gender
- Employees by Department
- Employees by Job Title
- Employment Type
- Average Vacation Hours

### Sales Breakdown
The breakdown page allows sales to be explored through different levels such as:

**Year → Category → Subcategory → Product → Channel**

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling

## Data Model

The project uses a fact and dimension table structure.

The main fact table is:

- `fact_sales`

Dimension tables include:

- `dim_product`
- `dim_product_category`
- `dim_product_subcategory`
- `dim_date`
- `dim_channel`
- `dim_employee`
- `dimension_customers`
- `dim_geography`
- `dim_loyalty_tiers`
